ℹ️ 关于 PriceScout

🎯 项目简介

PriceScout 是一款专业的AI硬件价格采集与对比工具，支持从京东、淘宝、拼多多等主流电商平台批量采集商品价格信息，提供数据清洗、智能排序、性价比推荐和数据可视化功能。

⚡ 核心功能

  • 多平台并发采集 - 同时从多个电商平台获取数据
  • 智能数据清洗 - 自动去除无效和重复数据
  • 性价比算法 - 基于价格、销量、评分计算性价比指数
  • 数据可视化 - 图表展示价格分布和趋势
  • 多种导出格式 - 支持 JSON、CSV 格式导出

🛠️ 技术栈

Python 3.10+ Flask Vue 3 ECharts Click asyncio
