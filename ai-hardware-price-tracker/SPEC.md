# AI硬件价格采集与对比工具 - 产品需求文档

## 1. 项目概述

### 项目名称
**PriceScout** - AI Infra硬件价格追踪器

### 核心功能
自动化从主流电商平台（京东、淘宝、拼多多）批量采集AI硬件商品价格信息，提供数据清洗、排序、对比分析和可视化展示。

### 目标用户
- AI工程师和研究员
- 企业采购人员
- 硬件发烧友
- 价格敏感型消费者

---

## 2. 功能规格

### 2.1 核心功能模块

#### A. 数据采集模块
| 功能 | 描述 |
|------|------|
| 多平台支持 | 京东、淘宝、拼多多 |
| 关键词搜索 | 支持按关键词批量采集 |
| 采集字段 | 商品名称、价格、销量、店铺评分、店铺名称、商品链接 |
| 采集数量 | 每个平台默认50条，支持配置 |

#### B. 数据处理模块
| 功能 | 描述 |
|------|------|
| 数据清洗 | 去除无效数据、统一价格格式 |
| 数据去重 | 基于商品名称和价格去重 |
| 排序功能 | 按价格升序/降序、销量、评分排序 |
| 数据导出 | 支持JSON、CSV、Excel格式导出 |

#### C. 分析与可视化
| 功能 | 描述 |
|------|------|
| 价格分布图 | 箱线图展示价格区间 |
| 销量对比图 | 柱状图对比Top10商品 |
| 性价比推荐 | 算法标注高性价比商品 |
| 平台对比 | 多平台同款商品价格对比 |

#### D. 命令行工具
| 功能 | 描述 |
|------|------|
| 交互模式 | 支持交互式输入关键词 |
| 批量模式 | 支持命令行参数批量执行 |
| 配置选项 | 平台选择、数量限制、输出格式 |

#### E. Web演示界面
| 功能 | 描述 |
|------|------|
| 关键词输入 | 支持关键词输入触发采集 |
| 实时进度 | 显示采集进度和状态 |
| 结果展示 | 商品卡片列表展示 |
| 图表可视化 | 内嵌图表组件 |
| 示例数据 | 初始化时展示示例数据 |

## 3. 技术架构

### 3.1 整体架构
```
┌─────────────────────────────────────────────────────────┐
│                    CLI / Web Interface                  │
├─────────────────────────────────────────────────────────┤
│                    Data Processor                       │
├─────────────────────────────────────────────────────────┤
│   ┌─────────┐    ┌─────────┐    ┌─────────────┐        │
│   │ JD API  │    │TB API   │    │ PDD API     │        │
│   └─────────┘    └─────────┘    └─────────────┘        │
└─────────────────────────────────────────────────────────┘
```

### 3.2 技术栈
- **后端爬虫**: Python 3.10+, requests, aiohttp, BeautifulSoup4
- **命令行**: Click框架
- **Web服务**: Flask + Vue3
- **数据可视化**: Chart.js, ECharts
- **数据存储**: JSON, SQLite

## 4. 界面设计

### 4.1 Web界面风格
- **设计语言**: 现代科技风格，赛博朋克元素
- **主色调**: 深蓝 (#0a1628) + 霓虹蓝 (#00d4ff) + 紫色 (#7c3aed)
- **字体**: JetBrains Mono (代码), Noto Sans SC (中文)
- **动效**: 渐入动画、数据流动效果

### 4.2 页面结构
1. **顶部导航**: Logo + 标题 + GitHub链接
2. **搜索区域**: 关键词输入框 + 平台选择 + 采集按钮
3. **结果区域**:
   - 商品卡片网格 (响应式)
   - 性价比标签
   - 排序控制
4. **图表区域**: 可折叠的价格分析图表
5. **导出区域**: 数据导出按钮
