# AI Infra硬件价格采集与对比工具 - 产品需求规格说明书

## 1. 产品概述

### 1.1 产品名称
**PriceScout AI** - AI基础设施硬件价格智能采集与对比系统

### 1.2 核心价值主张
为AI从业者、数据中心管理者和硬件采购人员提供一站式硬件价格情报服务，通过自动化采集多平台数据、智能分析和可视化呈现，帮助用户快速找到最具性价比的硬件采购方案。

### 1.3 目标用户画像
- **AI研究员与开发者**：需要采购GPU服务器、存储设备等AI基础设施
- **企业IT采购**：负责数据中心硬件采购的决策者
- **硬件发烧友**：关注最新硬件价格走势和技术选型
- **中小创业公司**：预算有限，需要精打细算的硬件采购

## 2. 功能需求

### 2.1 核心功能模块

#### 2.1.1 多平台数据采集
| 平台 | 采集字段 | 优先级 |
|------|----------|--------|
| 京东(JD) | 商品名称、价格、销量、店铺评分、评论数、链接 | P0 |
| 淘宝(Taobao) | 商品名称、价格、销量、店铺信誉、链接 | P0 |
| 拼多多(PDD) | 商品名称、价格、销量、店铺评分、链接 | P1 |

采集数据字段定义：
- **商品名称**：标准化处理，去除营销文案，保留核心产品信息
- **价格**：统一转换为人民币单位，标注是否含税
- **销量**：月销量/累计销量
- **店铺评分**：平台统一评分体系(0-5分)
- **网址链接**：原始商品页面URL

#### 2.1.2 关键词搜索采集
- 支持中英文关键词搜索
- 支持品牌筛选（如：NVIDIA、AMD、Intel）
- 支持型号精确匹配（如：RTX 4090、A100）
- 支持价格区间过滤
- 支持按销量/价格/评分排序

#### 2.1.3 数据清洗与去重
- 同一商品多平台识别与合并
- 去除无效/下架商品
- 价格异常值检测与标注
- 店铺黑名单过滤

#### 2.1.4 数据排序与展示
- 按价格升序/降序排列
- 按销量排序
- 按性价比指数排序
- 支持横向多商品对比（最多6款）

#### 2.1.5 数据可视化
- **价格趋势图**：展示历史价格走势
- **性价比雷达图**：综合评分可视化
- **价格分布直方图**：市场价位分布
- **竞品对比表**：关键参数横向对比

#### 2.1.6 性价比推荐
基于多维度计算性价比指数：
- 性能得分（基于规格参数）
- 价格得分
- 销量/热度得分
- 店铺信誉得分
综合加权得出最终推荐指数

### 2.2 用户交互场景

#### 场景一：命令行工具(CLI)
```
$ pricescout search "RTX 4090" --platforms=jd,taobao --sort=price
$ pricescout compare "A100" "H100" --output=csv
$ pricescout trend "RTX 4090" --days=30 --chart
```

#### 场景二：Web演示页面
- 输入关键词 → 触发采集 → 展示结果 → 支持对比操作
- 页面初始化时展示预设的GPU/服务器数据示例

## 7. 风险与约束

### 7.1 已知风险
- 电商平台反爬机制可能导致部分数据采集失败
- 价格数据存在实时波动，可能与实际有偏差
- 跨平台商品匹配存在一定误差
